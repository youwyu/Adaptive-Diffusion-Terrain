# ADEPT / ADTG project page

Project page for *Adaptive Diffusion Terrain Generator for Autonomous Uneven Terrain Navigation* (CoRL 2024) and
*ADEPT: Adaptive Diffusion Environment for Policy Transfer Sim-to-Real* (RSS 2025 Workshop ROAR), served at
https://youwei-yu.com/adtg-sim-to-real/ (a submodule of youwyu.github.io pinned to this `gh-pages` branch).

All assets are local. Media are losslessly optimised: videos are stream-copied with the index moved to the front
(`-movflags +faststart`), and the 115 MB field-trial clip is split at a keyframe into two parts (under GitHub's 100 MB
file limit) that the page plays back to back; PNGs are re-compressed losslessly (oxipng) with a lossless WebP copy
of the teaser; slider frames are losslessly re-encoded JPEGs (mozjpeg). Videos load only when scrolled into view.
